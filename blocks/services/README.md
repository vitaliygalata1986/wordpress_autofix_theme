# Послуги AUTO FIX

Блок `acf/services-section`, папка `blocks/services/`. Разметка — `services-section.php`, регистрация — `block.json`.

Для предпросмотра блока в Gutenberg используется `services.jpg`. Путь задан в `block.json` через `example.attributes.data.preview_image`; изображение показывается только в режиме предпросмотра редактора.

1. Импортируйте `acf-fields.json` через **ACF → Инструменты → Импорт групп полей**.
2. Добавьте блок **Послуги AUTO FIX** из категории **Секції AUTO FIX** на главную страницу. Якорь по умолчанию — `services`.
3. Заполните заголовок и текст рядом с ним, затем добавьте карточки и две строки подсказок по таблицам ниже.
4. Для первых шести карточек выберите категорию прайса и задайте подпись действия. Такие карточки ведут на `#prices` и передают фильтру выбранную категорию. Для остальных укажите телефон в ссылке, например `tel:+380931472022`.
5. В блоке подсказок включите «Відкривати діалог запису» для ссылки на консультацию, затем сохраните страницу.
