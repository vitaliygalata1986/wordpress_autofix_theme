# Зустрінемось на сервісі

Блок `acf/contacts-section`, папка `blocks/contacts/`. Разметка — `contacts-section.php`, регистрация — `block.json`.

1. Импортируйте `acf-fields.json` из этой папки через **ACF → Инструменты → Импорт групп полей**.
2. В Gutenberg на главной странице добавьте блок **Зустрінемось на сервісі** из категории **Секції AUTO FIX** после FAQ.
3. Проверьте поля на вкладках **Заголовок**, **Телефони**, **Адреса**, **Соцмережі**. Основные тексты, адрес и основной номер имеют исходные значения по умолчанию.
4. Добавьте дополнительные телефоны, ссылку на карту и соцсети по данным ниже, затем сохраните страницу.

JSON импортирует структуру полей. Строки репитеров и ссылки нужно заполнить самостоятельно. Для предпросмотра в выборе блоков используется `contacts.jpg`: путь задан в `block.json` через `example.attributes.data.preview_image`. PHP-шаблон показывает картинку только для этого примера в редакторе.

## Вывод

Блок выводится через `the_content()` в порядке блоков страницы. Старый `template-parts/contacts.php` и его закомментированное подключение удалены. Сохранены классы и структура исходной верстки, дополнительные CSS и JavaScript не требуются. Иконки встроены в шаблон, поэтому работают и в редакторе без SVG-спрайта шапки.

HTML-якорь по умолчанию — `contacts`: на него ссылаются меню и другие секции. При изменении якоря обновите эти ссылки. Блок разрешён один раз на страницу.

Поля относятся только к этой секции. Контакты в шапке, подвале, FAQ и других блоках автоматически не синхронизируются с ней.
