# Вартість робіт

Блок `acf/prices-section`, папка `blocks/prices/`. Разметка прайса и расчёта — `prices-section.php`, регистрация — `block.json`.

Для предпросмотра блока в Gutenberg используется `prices.jpg`; его путь задан в `block.json` через `example.attributes.data.preview_image`. Шаблон показывает это изображение только в режиме предпросмотра редактора.

1. Импортируйте `acf-fields.json` через **ACF → Инструменты → Импорт групп полей**.
2. На главной странице добавьте блок **Вартість робіт** из категории **Секції AUTO FIX** после услуг.
3. Проверьте подпись, заголовок, пояснение и примечание. Переносы строк задаются клавишей Enter.
4. Добавьте строки прайса из таблицы ниже. Категория строки управляет фильтрами, указанная цена участвует в расчёте.
5. При необходимости измените текст карточки расчёта и ссылку для уточнения цены.

## Начальные значения

- Подпись секции: `02 / ВАРТІСТЬ РОБІТ`.
- Заголовок: `Більше ясності.` / `Менше несподіванок.`.
- Метка: `Демонстраційний прайс`.
- Пояснение: `Ціни нижче — орієнтири для макета. Фактичну вартість і доступність послуг потрібно уточнити телефоном.`
- Примечание: `* Вартість залежить від моделі, стану авто та складності доступу. Запчастини й витратні матеріали розраховуються окремо. Це не остаточний кошторис.`
- Ссылка из карточки расчёта: `tel:+380660568121`, подпись `Уточнити ціну телефоном`.

JSON содержит структуру полей, а не повторяющиеся данные прайса; после импорта добавьте 11 строк из таблицы и сохраните страницу. Чекбоксы, фильтры, итоговая сумма и диалог списка используют существующий `assets/js/script.js`. Сохранены CSS-классы, ID и `data-category`. Цены демонстрационные; фактическую стоимость нужно уточнять у сервиса. Блок разрешён один раз на странице, HTML-якорь по умолчанию — `prices`.
