# Корисно знати

Блок `acf/faq-section`, папка `blocks/faq/`. Разметка — `faq-section.php`, регистрация — `block.json`.

1. Импортируйте `acf-fields.json` из этой папки через **ACF → Инструменты → Импорт групп полей**.
2. В Gutenberg на главной странице добавьте блок **Корисно знати** из категории **Секції AUTO FIX** после блока **Як це працює**.
3. Подпись, заголовок и пояснение имеют значения по умолчанию. Переносы в заголовке и пояснении задаются клавишей Enter.
4. Заполните контактную ссылку: URL `tel:+380660568121`, текст `+380 66 056 81 21`. Если поле оставить пустым, ссылка не выводится.
5. Добавьте вопросы и ответы в репитер, затем сохраните страницу. Порядок строк определяет порядок вопросов.

JSON импортирует структуру полей, а не содержимое страницы. Для ответов используется [визуальный редактор ACF](https://www.advancedcustomfields.com/resources/wysiwyg-editor/) с поддержкой абзацев и ссылок. Для телефонных ссылок указывайте адрес `tel:+380…`.

Для предпросмотра в выборе блоков используется `faq.jpg`: путь задан в `block.json` через `example.attributes.data.preview_image`. PHP-шаблон показывает картинку только для этого примера в редакторе. Исходные тексты ниже можно вставить во вкладке «Текст» поля ответа, чтобы сохранить ссылки.

## 1. Де розташований AUTO FIX?

```html
<p>Миколаїв, вул. Троїцька, 244, територія авторинку, бокс 10. Час приїзду та графік роботи уточніть телефоном <a href="tel:+380660568121">+380 66 056 81 21</a>.</p>
```

## 2. Як записатися на обслуговування?

```html
<p>Зателефонуйте за номером <a href="tel:+380660568121">+380 66 056 81 21</a>. Назвіть марку, модель, рік випуску та причину звернення. Для запису на розвал-сходження телефонуйте <a href="tel:+380931472022">+380 93 147 20 22</a>. Час візиту узгодьте заздалегідь. Чекаємо на авторинку: Миколаїв, вул. Троїцька, 244, бокс 10.</p>
```

## 3. Що робити, якщо авто не на ходу?

```html
<p>Зателефонуйте до служби евакуації: <a href="tel:+380954217415">+380 95 421 74 15</a>. Повідомте місце перебування та стан авто. Вартість і час подачі евакуатора узгодьте телефоном.</p>
```

## 4. Ціни на сайті остаточні?

```html
<p>Ні. Зараз на сайті розміщено демонстраційний прайс для попереднього розрахунку. Вказано лише орієнтовну вартість робіт, без деталей і матеріалів. Фактичну суму потрібно погодити з майстром.</p>
```

## 5. Чи можна приїхати зі своїми запчастинами?

```html
<p>Уточніть це під час запису. Повідомте виробника й артикул запчастини, щоб майстер міг перевірити сумісність та пояснити умови її встановлення.</p>
```

## 6. Що робити, якщо не знаю причину несправності?

```html
<p>Опишіть симптоми: незвичний звук, вібрацію, індикатор на панелі або зміну поведінки авто. Це допоможе визначити, з якої перевірки почати. Остаточний висновок потребує огляду автомобіля.</p>
```

## 7. Скільки часу займе ремонт?

```html
<p>Тривалість залежить від автомобіля, складності роботи, результатів діагностики та наявності деталей. Уточніть орієнтовний термін під час запису й погодьте його після огляду.</p>
```

Секция выводится через `the_content()` в порядке блоков страницы. Старый `template-parts/faq.php` и его закомментированное подключение удалены. Разметка и классы исходной секции сохранены; ответы раскрываются стандартными `<details>` / `<summary>`, без дополнительного JavaScript. Изначально все ответы закрыты, можно открыть несколько одновременно.

HTML-якорь по умолчанию — `faq`. Его можно изменить в дополнительных настройках блока; при изменении обновите ссылки на секцию. Блок можно добавить один раз на страницу. Необязательные пустые поля и строки без вопроса не выводятся. Стили редактора уже подключены на уровне темы.
