# Головний екран AUTO FIX

Блок `acf/hero-section` находится в категории **Секції AUTO FIX**. Вывод — `hero-section.php`, превью — `hero.jpg`.

1. Импортируйте `acf-fields.json` через **ACF → Инструменты → Импорт групп полей**.
2. Добавьте блок **Головний екран AUTO FIX** первым в содержимое главной страницы Gutenberg.
3. Отредактируйте тексты и при необходимости выберите фоновое изображение. Без выбранного изображения используется `assets/image/workshop.webp`; alt выбранного изображения берётся из медиатеки.
4. Заполните три ссылки:

| Поле | URL | Текст |
| --- | --- | --- |
| Основна кнопка | `#contacts` | Записатися на сервіс |
| Додаткова кнопка | `#prices` | Переглянути ціни |
| Посилання прокрутки | `#services` | ГОРТАЙТЕ ДАЛІ |

Тексты имеют исходные значения по умолчанию. В заголовке и описании Enter создаёт перенос строки. Заголовок разделён на обычный текст («Ваше авто.», перенос, «Наша») и выделенное слово «справа.». Адрес и подписи справа редактируются независимо от кастомайзера и блока контактов.

Пустые тексты и незаполненные ссылки не выводятся. Поля ссылок возвращают массив ACF Link; ссылки в новой вкладке получают `rel="noopener noreferrer"`. В JSON нет сохранённого содержимого страницы: ссылки нужно заполнить после импорта.

Сохранены классы hero и встроенная стрелка основной кнопки. Якорь по умолчанию — `hero`, поддерживаются пользовательский якорь и CSS-класс. Блок можно добавить на страницу один раз; он выводит заголовок H1. Картинка загружается с `loading="eager"` и `fetchpriority="high"`. Жёсткий preload старого изображения в шапке удалён, чтобы при выборе нового фона не загружалась лишняя картинка.

Старый `template-parts/hero.php` и его закомментированный вызов удалены. Блок выводится через существующий `the_content()`; добавление на страницу и импорт полей выполняются в админке.
