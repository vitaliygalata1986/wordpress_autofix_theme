# Наш підхід

Блок `acf/about-section`, папка `blocks/about/`. Разметка — `about-section.php`, регистрация — `block.json`.

Для предпросмотра блока в Gutenberg используется `about.jpg`. Путь к изображению задан в `block.json` через `example.attributes.data.preview_image`; шаблон выводит его только в режиме предпросмотра редактора.

1. Импортируйте `acf-fields.json` через **ACF → Инструменты → Импорт групп полей**.
2. На главной странице в Gutenberg добавьте блок **Наш підхід** из категории **Секції AUTO FIX** после блока с услугами и ценами.
3. Отредактируйте подпись, обе части заголовка и основной текст. Акцентная часть заголовка отображается красным; переносы задаются клавишей Enter.
4. Добавьте в репитер три преимущества из таблицы ниже. Номера пунктов и порядок отображения формируются автоматически.
5. При необходимости измените подписи над и под схемой, затем сохраните страницу.

Поля с одиночными текстами заполнены содержимым исходной секции. В JSON хранится структура полей, а фактические данные блока сохраняются в записи WordPress. Репитер преимуществ после добавления блока заполните значениями из таблицы:

| Заголовок | Описание |
| --- | --- |
| Сучасне обладнання | Німецький вібростенд створює навантаження на ходову під час перевірки. Оцінюємо її роботу, щоб знайти причину несправності. |
| Зрозумілий результат | Пояснюємо, що показала діагностика, та погоджуємо необхідні роботи до початку ремонту. |
| Від діагностики до ремонту | Обслуговуємо авто комплексно: ходова, розвал-сходження, дизельні паливні системи, зварювальні роботи та капітальний ремонт двигуна. |

SVG-схема и подписи направлений («ДВИГУН», «ГАЛЬМА», «КЛІМАТ», «ПІДВІСКА») остаются частью шаблона.

Секция сохраняет CSS-классы исходной разметки, поэтому отдельные стили и JavaScript для блока не нужны. HTML-якорь по умолчанию — `about`, его использует меню. Блок разрешён один раз на страницу. Старый `template-parts/about.php` больше не используется: секция размещается и упорядочивается через `the_content()` в Gutenberg.
