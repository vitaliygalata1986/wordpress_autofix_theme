# Наш сервіс зблизька

Блок `acf/gallery-section`, папка `blocks/gallery/`. Разметка — `gallery-section.php`, регистрация — `block.json`.

1. Импортируйте `acf-fields.json` через **ACF → Инструменты → Импорт групп полей**.
2. На главной странице в Gutenberg добавьте **Наш сервіс зблизька** из категории **Секції AUTO FIX** перед блоком процесса.
3. Подпись, заголовок, описание, доступная назва галереи и подсказка имеют исходные значения по умолчанию. Переносы в текстовых областях задаются клавишей Enter.
4. Загрузите фотографии в медиатеку и добавьте строки репитера: изображение и подпись. В свойствах изображения заполните альтернативный текст. Порядок строк определяет порядок фото, номера `01 /`, `02 /` формируются автоматически.
5. Сохраните страницу. JSON содержит структуру полей, а не фотографии и строки репитера.

## Превью и поведение

Путь к картинке превью задан в `block.json` через `example.attributes.data.preview_image`. Положите скриншот секции в эту папку и используйте соответствующее имя файла. Пока изображение отсутствует, выбор блока показывает текстовую заглушку.

В редакторе добавленный блок показывает горизонтальный список фото. На сайте используется уже подключённый Swiper: автоматическая смена каждые 5 секунд, пауза, стрелки и точки. При небольшом количестве фото циклическое перелистывание отключено; один кадр не требует элементов управления. Без Swiper остаётся горизонтальный список, без JavaScript ссылка открывает изображение в новой вкладке.

Просмотр полного фото использует общий `template-parts/dialog-gallery.php` из подвала. Этот файл сохраняется. Старый шаблон секции `template-parts/gallery.php` удалён, вывод идёт через `the_content()`.

Якорь по умолчанию — `gallery`, его использует меню. Блок разрешён один раз на страницу. Пустые или удалённые изображения пропускаются. Если фотографий ещё нет, редактор показывает подсказку для заполнения; демонстрационные фото на сайт автоматически не подставляются.
