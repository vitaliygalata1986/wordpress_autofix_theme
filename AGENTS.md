# Repository Guidelines

## Scope & Workflow

Work within `wp-content/themes/autofix/`. Maintain theme-specific contributor guidance in this file. Make changes gradually, following the user's requested step; avoid expanding a CSS task into JavaScript, markup, or other migration work.

## Theme Structure

- `functions.php`: theme setup and inclusion of PHP modules from `inc/`.
- `inc/enqueue.php`: style/script enqueue function and its `wp_enqueue_scripts` hook; loaded with `require_once` from `functions.php`.
- `inc/customizer.php`: logo text/subtitle controls in Site Identity; native `custom-logo` support is declared in `functions.php`.
- Телефоны шапки: раздел кастомайзера «Телефони в шапці» содержит подпись и номер для автосервиса, эвакуатора и развал-схождения. Общие исходные значения — `autofix_header_phone_defaults()` в `inc/customizer.php`, вывод — `template-parts/header-phones.php`. Пустой номер скрывает строку; ссылка `tel:` строится из номера автоматически. Эти настройки относятся только к шапке, контакты других секций и метаописание редактируются отдельно.
- `header.php`, `index.php`, `footer.php`: WordPress templates.
- Раздел кастомайзера «Футер»: `autofix_footer_text` — текст с переносами строк, `autofix_footer_address` — адрес. В `footer.php` значения экранируются; пустые поля скрываются. Год копирайта выводится через `wp_date('Y')` с часовым поясом WordPress; обновление года через JavaScript удалено.
- Меню шапки: область `header` («Меню в шапці») регистрируется в `autofix_setup()`; `header.php` выводит её через `wp_nav_menu()` со стандартным Walker и глубиной 1. Меню назначено в админке; проверка `has_nav_menu()` и запасные статические ссылки удалены, `fallback_cb` отключён. `.header-menu` поддерживает список WordPress и две колонки на мобильных экранах; `#navigation` остаётся контейнером для существующего JavaScript.
- `template-parts/`: remaining static homepage sections and standalone blocks. Section calls in `index.php` are currently commented out; page content is rendered through `the_content()` in Gutenberg order.
- `template-parts/dialog-*.php`: contact, gallery, and selection dialogs, included by `footer.php` before `wp_footer()`.
- `template-parts/logo.php`: shared header/footer logo; uses the uploaded custom logo or `assets/image/logo.webp`, plus sanitized theme text settings.
- `style.css`: WordPress theme metadata.
- `assets/css/style.css`: site styles.
- `assets/vendor/swiper/`: bundled Swiper assets.
- `assets/js/` and `assets/image/`: site scripts and images.
- `index.html`: static source layout for reference.
- `blocks/hero/`: ACF-блок `acf/hero-section`, шаблон `hero-section.php`, `acf-fields.json`, превью `hero.jpg` и инструкция `README.md`. Заголовок H1, описание, фон, кнопки, адрес и подписи редактируются в Gutenberg.
- `blocks/process/`: ACF-блок `acf/process-section`, PHP-шаблон, превью и отдельный `acf-fields.json` для ручного импорта; инструкции в `README.md` рядом.
- `blocks/about/`: ACF-блок `acf/about-section` с редактируемыми текстами секции, преимуществами и JPG-превью для Gutenberg; схема автомобиля остаётся встроенной SVG-разметкой.
- `blocks/services/`: ACF-блок `acf/services-section` с редактируемыми заголовками, карточками услуг, контактными строками и JPG-превью для Gutenberg.
- `blocks/prices/`: ACF-блок `acf/prices-section` с редактируемым прайсом и встроенной оценкой стоимости; расчёт продолжает использовать `assets/js/script.js`.
- `blocks/faq/`: ACF-блок `acf/faq-section`, PHP-шаблон `faq-section.php`, отдельный `acf-fields.json` для ручного импорта и `README.md` с исходными ответами. Превью использует JPG из папки блока; путь задан в `example.attributes.data.preview_image` файла `block.json`.
- `blocks/contacts/`: ACF-блок `acf/contacts-section`, PHP-шаблон `contacts-section.php`, отдельный `acf-fields.json` для ручного импорта и `README.md` с исходными контактами. Превью использует JPG из папки блока; путь задан в `example.attributes.data.preview_image` файла `block.json`.
- `inc/acf-gutenberg-register-blocks.php`: регистрация ACF-блоков услуг, стоимости, About, галереи, процесса, FAQ и контактов, а также общей категории. Разметка этих секций находится в соответствующих папках `blocks/`; прежние статические шаблоны удалены после перехода на `the_content()`.

## Asset Conventions

Enqueue styles through `wp_enqueue_scripts` in `inc/enqueue.php`, using WordPress theme URL helpers. Load Swiper CSS before the main site stylesheet through explicit dependencies. Avoid duplicate stylesheet links in templates. Preserve existing style handles and use the theme version for asset versioning.

Enqueue scripts through the same hook, with `defer` and footer loading. Declare `autofix-swiper` as a dependency of `autofix-main` so the library loads first. Avoid direct script tags in PHP templates.

## Style & Validation

Keep static section markup in descriptively named template parts (`hero.php`, `services.php`, `gallery.php`). After migrating a section to ACF/Gutenberg, keep its PHP markup in `blocks/<section>/` and remove the obsolete template part and its references. Preserve section IDs, CSS classes, and data attributes used by navigation and scripts when moving markup.

Match the surrounding PHP style and four-space indentation. Preserve unrelated user changes. Run `php -l` on modified PHP files and check the scoped diff for whitespace errors. Report browser verification separately from static checks.
